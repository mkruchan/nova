One-time setup needed. This app needs a free Supabase project so your data syncs between devices.

1. Create a project at supabase.com (free tier).

2. In the SQL Editor, run the schema from nova-schema.sql (provided alongside this file).

3. In Project Settings → API, copy your Project URL and anon public key.

4. Open this file in a text editor, find the CONFIG block near the top of the <script>, and paste both values in. Save, re-open, and re-host it.
